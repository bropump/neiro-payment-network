# Agent operator setup

**Follow [AGENTS.md](../AGENTS.md).** It is the single ordered agent procedure, with commands, required evidence and recovery guidance.

The five stages are:

1. Verify latest upstream-main Kora and install the runner.
2. Configure the chosen signer, fees, limits and funding.
3. Protect the listing and verify running Kora enforces it.
4. Publish, supervise renewal and configure upstream update checks.
5. Verify a transaction and report PASS / FAIL / NOT RUN with evidence.

[Host and installation details](OPERATOR-SETUP.md) provide supporting instructions. [Operations and recovery](RENEWAL.md) cover changes, interrupted sends and retirement. Do not treat a running service, successful quote or discovered listing as a completed payment test.
